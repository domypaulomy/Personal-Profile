# 🌐 PERSONAL PROFILE

## Web & Android Developer | Bridging Hardware and Software with Digital Solutions

Selamat datang di halaman profil saya! Saya adalah seorang **Web dan Android Developer** yang berfokus pada pembangunan infrastruktur digital, aplikasi mobile, dan platform integrasi data. 

Sebagai seorang putra daerah asli dari **Pulau Sabu, Kabupaten Sabu Raijua, Nusa Tenggara Timur (NTT)**, saya memiliki misi untuk terus berkembang di industri teknologi dan menghadirkan solusi digital yang berdampak nyata bagi masyarakat maupun ekosistem digital.

Spesialisasi saya terletak pada kemampuan membangun "jembatan digital"—mulai dari aplikasi Android yang interaktif, sistem informasi berbasis web, hingga dasbor (*dashboard*) khusus yang mengintegrasikan data dari perangkat keras (hardware/IoT) agar dapat dipantau dan dikelola dengan mudah oleh pengguna.
